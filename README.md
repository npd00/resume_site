# Resume Site

Source for https://npdfw.com, hosted on Cloudflare Pages (project `npdfw`).

Imported from the live Pages site on October 22, 2026. This static version replaces the former WordPress theme; the previous files remain available in Git history.

## Files

- `index.html`: page content and inline scroll animation script
- `styles.css`: styling and responsive layouts
- `favicon.svg`: site icon

Google Fonts are loaded externally. No build step or package installation is required. Preview using `python3 -m http.server 8000` and open http://localhost:8000.

## Cloudflare Pages settings

- Production branch: `main`
- Build command: leave blank
- Output directory: repository root
